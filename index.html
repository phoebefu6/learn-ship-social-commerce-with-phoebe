Ship It: Social Commerce, End to End

One social-commerce data estate, built in the order its layers depend on each other. Serai Commerce, a constructed Southeast Asian enabler running 48 brands across three marketplaces, receives one export per marketplace; underneath are 8,614 real orders from the public Olist dataset. Six leader sessions decide what to build, in what order, what a model and a copy assistant are worth, and what the data product can charge. Ten builder sessions build it: the merged schema, tests that fail loudly, Building the metric registry, cohorts, a repeat-purchase model and its leak hunt, scored listing copy and review summaries, a seller-support agent with evals, the packaged product, and a five-layer bench computed in your browser.

Builder track 🔧 · ten sessions, Python and the browser

Serai's estate built layer by layer in the order the data flows, from three raw exports to a bench that runs all five layers at once.

🗂️ Builder session 1 · start here

The merged schema

Five tables with declared grains and an order-level fact table, built in pandas on the public Olist file, and the join that inflates item value by 4.48%.

▶ Start here 🚨 Builder session 2

Data-quality tests that fail loudly

Keys unique, customer keys resolve, timestamps in order, amounts not negative: pass rates per export, and a repair, quarantine or flag rule for each.

 📏 Builder session 3

Building the metric registry

Orders, GMV and repeat rate as tested definitions, checked against a naive sum and a reference total.

 🔁 Builder session 4

Cohorts and repeat purchase

Monthly cohorts on the repaired rows, repeat within 90 days, and the same-day repeat orders hiding in the real data.

 📈 Builder session 5

A repeat-purchase model with a time split

Features as of purchase, a label window that closes before the cutoff, logistic regression, AUC and lift on the next month.

 🕵️ Builder session 6

The leakage hunt

A backfilled field that makes training look perfect and the next month fall apart, and the learn-predict separation that stops it.

 🧾 Builder session 7

Listing copy and review summaries, scored

The rubric as code over twenty pre-written outputs, facts recomputed from rows, and a golden set that checks the checker.

 🤝 Builder session 8

A seller-support agent and its evals

One support agent with narrow tools, golden questions, a hand-off, and the excessive-agency risks its evals must catch.

 📦 Builder session 9

Packaging the data product

What ships: tables, definitions, scores and the copy assistant, with tests as the service levels and a price range on top.

 🎛️ Builder session 10

The five-layer value bench

All five layers computed live on 8,614 real orders, an anti-lever that skips data engineering, and a break button that leaks a field from the future.

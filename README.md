# Ship It: Social Commerce, End to End

An interactive course by Phoebe Fu: one social-commerce data estate built in the order its layers
depend on each other (data engineering, analytics, machine learning, gen AI, and a packaged data
product). Six leader sessions and ten builder sessions, 45 minutes each, on Serai Commerce, a
constructed enabler, over 8,614 real orders derived from the Brazilian E-Commerce Public Dataset by
Olist (CC BY-NC-SA 4.0; derived and masked rows, no review text).

The capstone is a five-layer bench computed in the browser (`assets/ssc-live.js` on
`assets/ssc-data.js`), with an anti-lever that skips the data engineering layer and a break button
that leaks a field from the future. An independent Python reference agrees with it on every number.

Open `index.html` to start.
